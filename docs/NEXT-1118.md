# NEXT-1118：限流网关 / API 用量控制台 / 今日雷达（续聊先读这里 + NEXT.md + NEXT-1116.md）

## 已完成（构建 #102 成功，引擎已部署）
- **全局限流网关** `ios/App/GateNet.swift`：URLProtocol 拦截 URLSession.shared 的 GET（GeckoTerminal / Dexscreener API / GoPlus / RugCheck / Honeypot / Jupiter / Blockscout / CoinGecko），同域名排队（前台先于后台）、相同请求合并、短缓存（404 也缓存 ≤60s）、429/1015 整域冷却并按 Retry-After 重试、仍失败回退旧缓存（响应头 X-Gate-Stale）。`DataGate` 只保留接口，不再单独排队。
- 规则按官方文档校正：Gecko 30/分；Dexscreener 池子/代币 300/分、资料/置顶/广告/metas 60/分；Jupiter 无密钥 0.5/秒（间隔 2.1s）；CoinGecko 无密钥约 10–30/分（间隔 4s）；GoPlus 免费 150 CU/分、3 万/日、15 万/月。
- **API 用量控制台** `ios/App/GMUsage.swift`：设置 → 数据与密钥 → 「API 用量控制台」、盯盘看板里也有入口。手机端计数（真实发出的请求，UTC 日/月，存 UserDefaults `gmUsageV1`）+ 引擎 `/e/usage`（Worker 端计数）。官方额度表每项带来源链接；官方没公布的（RugCheck、Honeypot、Blockscout）只统计已用，不编数字。
- **引擎计数** `worker-engine/usage.js`：包装全局 fetch，按供应商记入 D1 `api_usage(day, provider, calls, units)`；Alchemy 按官方 CU 表估算（getLogs 60、call 26…），Helius 按 credits 估算（标准 RPC 1、DAS 10、Enhanced Transactions 100）。每次上游调用约写 2 行 D1（免费 10 万行/日）。`/e/usage` 同时回传 Groq 实测响应头（剩余请求/令牌）。已用队列探测验证：helius 3、dexscreener 2、groq 3，Groq 实测 999/1000。
- **今日雷达** `ios/App/GMScout.swift`：App 在前台 + 近 1 分钟 gecko ≤8 次 + 网关无排队请求 + 距上次 ≥30 分钟 → 自动扫描（后台优先级，每日预算 gecko 400 / dexscreener 600 / goplus 120 / rugcheck 120）。流程：7 条链趋势池算热度 → Dexscreener 热门叙事 → 可靠性初筛（流动性≥5 万、池龄≥6h、买家≥150/卖家≥80、买卖笔数比 0.6–1.8、成交/流动性 0.2–30、FDV/流动性≤150、24h≥-50%、1h≤+150%）→ GoPlus(EVM)/RugCheck(SOL) 合约扫描（高危直接剔除）→ 前 4 个币取最近 300 笔成交找盈利钱包（买卖都有、卖价≥买价×1.15、≤40 笔、估算盈利≥$300）累计到本机榜单（14 天，≤400）；有 GMGN 密钥时补 `/v1/user/smartmoney`（字段为推测，需实测）。
