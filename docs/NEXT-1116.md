## 第三轮（build 100）：交易记录 / 钱包分析第二代（`ios/App/GMLab2.swift`）
- `GLArchive`：成交在本机累积（Caches，最多 3000 笔/币）；新一批和库里最新成交接不上（离开页面太久有缺口）就丢弃旧库、窗口重新开始，保证 FIFO 配对连续。`GMLabStore.load` 先读库再合并，`rep2 = GL2Calc.build(...)`；`GMLabStore.clearArchive(vm)`。
- `GL2Calc`（先调 `GLCalc.build` 拿基础报告，再加）：钱包 FIFO 配对（已兑现/浮动盈亏、持有时长、配对胜率、买入位置分位、老仓卖出、已清仓/持有中）、标签（追高/低吸/秒进秒出/短线/拿得住/定时节奏/固定金额/对倒/同块买卖 MEV/持有榜）、买卖方均价、累计净流入 vs 价格背离（全窗口 + 最近三分之一）、盈利盘 vs 套牢盘及被套成本区、持有榜大户动向（只能匹配直接以该地址发起交易的大户）、大卖单 5 分钟承接率、已兑现利润集中度、MEV 占比、单笔规模趋势、近期买家筹码成本分布。
- 视图：`GMTradeLab2View`（结论、买方 vs 卖方、资金 vs 价格折线、筹码成本分布、档位、成交明细带筛选）、`GMWalletLab2View`（排序：成交额/盈亏/最近；筛选：全部/盈利/亏损/持有中/已清仓/机器人/持有榜/关注；赚得最多/亏得最多；持有榜大户动向；钱包行可展开看 FIFO 明细和该钱包成交，带链上交易链接；☆ 关注钱包，列表存 UserDefaults `gmWatchList`）。
- 旧的 `GMTradeLabView`/`GMWalletLabView` 还在 GMLab.swift 里，已不被使用。
