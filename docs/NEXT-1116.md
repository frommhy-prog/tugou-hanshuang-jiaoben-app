- 下拉刷新：刷新时内容整体下移 52pt，图标放在空出的位置；去掉图标外围白色圆盘和阴影（`GMMore.swift` 的 `GMPullView`、`LogoRefreshHook(refreshing:)`）。
- 代币页隐藏导航栏（`.toolbar(.hidden, for: .navigationBar)`），搜索/☆/⤢/⋯ 并进头部；⋯ 菜单含 工具箱、盯盘看板、分享、设提醒、外链、复制合约。通知名：`.gmOpenSearch/.gmOpenDash/.gmShare/.gmAlert/.gmOpenTools`，由 `UnifiedTokenRoot` 接收。
- 价格/市值跟随计价货币（`GMPx`，写法 `¥0.0₄123`）；K 线 payload 带 `rate/cur`（`chart.html` 的 `S.R/S.cur`）；汇率缺失时 `GMPx.ensureFX()`：open.er-api.com → frankfurter → 引擎 `/api/fx`；`UnifiedTokenRoot` 对内容 `.id(币种|汇率版本)` 强制重绘。
- `ios/App/GMFree.swift`：免 GMGN Key 的数据源回落 `GMFreeStore`（OKX Web3 需用户免费 Web3 Key → 币安 Web3 公共接口 → Blockscout → GoPlus → RugCheck → Jupiter lite → Honeypot.is），`GMToolbox` 工具箱（用户给的整份清单），`GMFreeSettings`（设置里填 OKX Web3 Key）。币安/欧易交易所 API 密钥不含链上持仓数据。

## 第二轮（build 98）
- 全 App 的 `Fmt2.usd(` 被补丁 `g22_fiat_*` 批量替换成 `GMPx.fiat(`（`Money.format`，跟随计价货币）。之后新写的代码一律用 `GMPx.fiat`，不要再用 `Fmt2.usd`。
- 头部标签 `tagsRow` 去掉横滑，一行放下（叙事标签可被截断，DEX 标签优先），链名由头像角标显示；头像 44；数据条 `GMMetricStrip` 的 cell 改成单行（名称+数值）。
- K 线下面「分析功能」宫格 + 「最新成交」被替换为分析分页 `GMTabsSection`（`GMTabs.swift`）：交易记录 / 钱包分析 / 持有者 / 流动性 / 综合研判 / 合约安全 / 叙事社交 / 庄家情报 / 更多工具。设置里 `GMTabSettings`：显示方式（标签栏/胶囊/宫格）、吸顶、默认页、排序与显示（`GMTabEditor`）。页内容由 `UnifiedTokenRoot.tabBody(_:)` 提供；旧入口 `.tstzmOpenPage(Int)` 由 `GMTabState.open(_:)` 映射到分页。
- `ios/App/GMLab.swift` 自带分析工具（数据：GeckoTerminal 最深池最近 300 笔成交，含代币数量/区块/发起地址）：
  - `GMTradeLabView` 交易记录分析：大单/小单净流向（档位）、成交集中度、机器人/刷量占比（定时节奏、固定金额、对倒）、同区块多钱包买入、最大卖家盈亏、窗口内买家平均成本 vs 现价、价格冲击斜率、成交加速度、买卖笔数 vs 金额背离、持有榜地址卖出；成交明细。
  - `GMWalletLabView` 钱包分析：活跃地址的买卖、均价、已兑现/浮动盈亏、标签。
  - `GMLiquidityLabView` 流动性：按 v2 恒定乘积粗估的退出深度（卖出滑点、可退出金额）、市值/流动性、前十与 Dev 持仓市值相对池子深度的倍数。
  - `GMTrendCard`：本机每 2 分钟记一个点（价格/流动性/市值/持有者/前十），算全程与近 1 小时变化（`GMTrend`，UserDefaults，最多 400 点/币）。
- 旧的 `GMFuncGrid`、`GMTradesMini` 还在 `GMKit.swift`，已不被使用。
